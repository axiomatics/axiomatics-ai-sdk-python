# strands

Attaches one Strands intervention handler to an existing `Agent` and enforces `BEFORE_MODEL`, `TOOL_VISIBILITY`, `BEFORE_TOOL`, `AFTER_TOOL`, and `AFTER_MODEL` at the PDP. A tool call the policy wants a human to approve pauses the agent with a Strands interrupt.

# google_adk

Attaches PDP authorization to a Google ADK agent through its callbacks (no wrapping), enforcing `BEFORE_MODEL`, `TOOL_VISIBILITY`, `BEFORE_TOOL`, `AFTER_TOOL`, and `AFTER_MODEL`. A tool call the policy wants a human to approve pauses with ADK tool confirmation.
